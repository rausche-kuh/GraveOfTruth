# Odin's Paths

Nobody walks to a boss in a straight line. Odin's Paths lets the world wear its own trails: read
a vegvisir, sleep, and in the morning a path leads from home toward the altar it revealed —
around the hills rather than over them, along the valleys, down to the shore and on again from
the next island.

> **Planned, not built:** this is an early scaffold. Nothing below works yet. The mod is
> developed heavily with the use of AI.

## What it will do

- **Paths to the altars** — when a vegvisir reveals a boss altar, the next time the world sleeps
  a trail is laid to it. It starts from the nearest point of the path network: the sacrificial
  stones where every Viking wakes, a base you have marked, or a path that is already there, so
  the trails grow into a network rather than a bundle of lines.
- **Like a real path** — the trail follows the easiest ground and avoids climbing, so it winds
  through the land the way old footpaths do. Where the sea is in the way it ends at the shore and
  carries on from the far one.
- **Clears the way** — grass gives way to packed dirt, and in the Deep North the path is dug out
  of the snow.

## Without the mod

The paths are ordinary terrain, stored the way the game stores anything you dig or hoe: they stay
when the mod is removed, and players without the mod see them too.

## Multiplayer

Server side: install it on the dedicated server, or on the machine that hosts the world. Players
do not need it.

## Install

A mod manager (Gale or r2modman), or drop the zip's contents into
`BepInEx/plugins/rauschekuh-OdinsPaths/`. Requires the BepInEx pack for Valheim.
